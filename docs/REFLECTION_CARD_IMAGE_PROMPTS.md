本文件用于卡牌视觉设计与图像生成，不是用户界面文案。大阿卡纳名称、原型编号以及 Tender/Fierce 字段均为内部设计依据，不应显示在卡面或反思流程中。

每张牌对应的自我善意、共同人性、正念候选，以及LLM可使用的图案锚点、关系结构、激活条件和禁止解释，见 [REFLECTION_CARD_LLM_GUIDANCE.md](./REFLECTION_CARD_LLM_GUIDANCE.md)。图像提示词与LLM目录必须使用同一标题和同一画面结构。

## 使用方式

1. 每次生成只处理一张牌，并把风格参考图作为“图像1”上传。
2. 复制对应代码块作为完整提示词，不要只输入场景段落。
3. 初次生成使用 2:3 竖版；若结果接近目标，后续每轮只修改一个问题。
4. 参考图只控制线条、造型、色彩、纸张质感和童话气质，不复制其人物、符号、文字或构图。
5. 每张图必须同时呈现：可直接理解的动作、该动作的实际作用、它可能产生的代价，以及一个尚未完成的选择。

## 0. 未定之步 / The Unwritten Step

**原型来源：** 愚者——进入未知、开始旅程，但不把冒险浪漫化。

**核心张力：** 在结果尚不确定时，停下来是在保护自己，还是不确定性逐渐成为不行动的理由？

**Tender（内部）：** 没有准备好和害怕做错，不代表软弱或失败。

**Fierce（内部）：** 是否可以承担一个很小、可撤回并且能够验证的尝试？

```text
【参考图】
图像1仅作为粗圆深色手绘线、扁平童话造型、复古套色、彩铅与干性水粉颗粒、温暖纸张底纹参考。不要复制原有人物、服装、狗、手杖、悬崖、太阳、云朵排列、文字或构图。不要生成实体卡牌或样机。

【目标与格式】
创作一幅原创、正面、平视、满版的2:3竖版反思卡插画。不要牌名、编号、文字、logo或水印。画面不判断前进或后退哪一个正确。

【场景】
一名年龄不明确、五官极少、比例略带童话感的人站在一条尚未铺完的普通石路前，一只脚轻微抬起，停在落下之前。前方只有三块间距合理但不完全整齐的踏石，之后进入薄雾；身后放着一个打开的小包，里面能看到水瓶、布和一件普通工具，物品没有整理完但并非毫无准备。

【双义性】
人物可能准备向前，也可能正在收回脚。薄雾只是未知，不是危险；包里的物品可能已经足够支持一个小步骤，也可能仍需补充。踏上第一块石头不会承诺整段旅程。

【构图与限制】
人物、抬起的脚和第一块踏石构成视觉中心。前方不能更明亮、更高贵或像命定道路，身后也不能成为黑暗退路。使用赭黄、砖红、鼠尾草绿、褪色蓝和奶油色。不要悬崖、坠落、发光道路、胜利姿态、恐惧表情、传统愚者符号、魔法、摄影、3D或光滑矢量风。
```

## I. 可用之手 / The Capable Hand

**原型来源：** 魔术师——调用已经存在的资源与能力，而不是等待完美条件。

**核心张力：** 用户是真的缺少行动条件，还是暂时看不见已经拥有的资源？

**Tender（内部）：** 疲惫、害怕失败或任务复杂，都可能让能力暂时难以被看见。

**Fierce（内部）：** 能否选用一项已有能力、一个工具或一位可以求助的人？

```text
【参考图】
图像1只用于手绘轮廓、扁平造型、复古色彩、粉质颗粒和旧童话书气质。不要复制参考图的人物、道具、动物、太阳、文字或构图。不要生成实体卡牌。

【目标与格式】
原创、正面、略微俯视、满版2:3竖版插画；无牌名、编号、文字、logo和水印。画面不把自己完成、使用工具或求助中的任何一种突出为唯一答案。

【场景】
一张有使用痕迹的木桌上铺着一只经常使用的厚布袋。布袋左下角已经缝好一块形状不规则的补丁，针脚不完全整齐但牢固，清楚表明人物此前完成过一次实际修补。

布袋右侧接缝处还有一道新的短裂口。裂口比旧补丁所在的位置稍厚，其中一端已经用普通固定针暂时别住。人物一只手把裂口附近的布料压平，另一只手拿着一根已经穿好线的针，针尖停在落下之前。

旁边只有一小卷同色线、一块尚未裁剪的布片、一个顶针和一把闭合的小剪刀。线和布片看起来可以开始修补，但无法确定是否足够处理较厚的接缝。

【双义性】
旧补丁是人物已经使用过能力和工具的可见证据，但不能证明新的裂口一定能用相同方式处理。人物可能准备落下下一针、继续检查接缝、换一种材料，或请更有经验的人帮忙。现有条件并非完全不足，也不保证足以完成全部修补。

【构图与限制】
已经缝好的补丁、新裂口和穿好线的针形成清楚的三角构图，让观者先看懂“这里已经修好过一处，现在还有另一处需要处理”。两只手结构自然，针尖没有刺入手指。

人物姿态稳定，不表现无能、天赋觉醒或万能控制。使用粗圆略抖的线、彩铅水粉颗粒和温暖纸底。不要魔杖、无限符号、四元素祭坛、发光针线、完美工艺展示、血迹、写实手部、摄影、3D或光滑矢量。
```

## II. 合上的盒子 / The Closed Box

**原型来源：** 女祭司——尊重尚未准备公开或理解的部分，同时承认已经知道的内容。

**核心张力：** 保留沉默和隐私是在保护需要，还是在回避一个已经隐约知道的事实？

**Tender（内部）：** 不必立刻打开、解释或公开所有内在经验。

**Fierce（内部）：** 即使保留未知，是否仍能具体说出自己已经确认的部分？

```text
【参考图】
图像1仅用于粗圆手绘线、简化童话比例、复古套色、彩铅水粉肌理和纸张颗粒。不要复制参考图人物、狗、手杖、悬崖、太阳、文字或构图。不要生成卡牌摄影。

【目标与格式】
原创、正面、平视、满版2:3竖版插画；不要牌名、编号、文字、logo或水印。画面不要求人物打开盒子。

【场景】
人物坐在普通桌边，面前放着一个合上但没有上锁的小木盒。盒子旁已有两件从中取出的普通物品，例如一段布和一颗纽扣，说明并非所有内容都完全未知。人物一只手平放在盒盖上，另一只手轻轻握着已经取出的物品，动作停顿但不紧张。

【双义性】
盒子可能保存隐私、记忆或尚未整理的内容。人物可以打开、继续合上，或只处理已经取出的部分。合上不等于逃避，打开也不自动等于勇敢。

【构图与限制】
盒子、盒盖上的手和已取出的两件物品为中心。盒内不得发光，不出现秘密文字、锁链、钥匙孔特写、神谕、卷轴或神秘威胁。人物表情中性。使用暖黄、旧红、灰蓝、鼠尾草绿和奶油色；不要传统女祭司符号、月冠、柱子字母、魔法、摄影、3D。
```

## III. 添上的一碗 / The Bowl Set Down

**原型来源：** 女皇——让照顾成为真实的滋养，而不是价值证明。

**核心张力：** 当前最需要的是补充、安慰与恢复，还是照顾已经变成无限延后其他需要的方式？

**Tender（内部）：** 身体和情绪需要食物、水、温暖与休息，无须先证明自己值得。

**Fierce（内部）：** 哪一种照顾能让容量真正恢复，并为之后的选择留下入口？

```text
【参考图】
图像1只用于粗圆线条、扁平童话形体、复古套色、粉质颗粒和温暖纸张质感。不要复制参考图场景、人物、动物、太阳或文字。不要生成实体卡牌样机。

【目标与格式】
原创、正面、平视、满版2:3竖版反思插画；无牌名、编号、文字、logo或水印。画面不把照顾表现为奖励或奢侈。

【场景】
一张低桌旁有一把带薄毯的椅子。人物正在把一碗简单温热的食物和一杯水放到桌上，旁边还有一件暂时放下的日常任务物品，例如针线、书或小工具。食物份量普通，桌面仍留有空间，房间有人生活但不华丽。

【双义性】
这碗食物可能是人物为自己准备，也可能为稍后到来的人准备。任务可以在恢复后继续，也可能需要重新安排。照顾是实际需要，但画面不暗示休息多久才正确。

【构图与限制】
放下碗的动作是视觉中心，任务物品只作次要线索。不要丰饶女神、王冠、麦田、奢华宴席、母职刻板印象、治愈光芒、空荡贫困、过度悲伤、摄影、3D或商业绘本光滑风。保持复古暖色、手绘错位和纸张颗粒。
```

## IV. 半开的门 / The Half-Open Door

**原型来源：** 皇帝——建立结构和边界，同时检查结构是否变得僵硬。

**核心张力：** 关闭一扇门是在保护安全与容量，还是在避免需要面对的表达？

**Tender（内部）：** 拒绝、退出和保持距离有时是合理的保护。

**Fierce（内部）：** 这扇门需要更明确地关闭、重新打开，还是通过一次诚实说明确定距离？

```text
【参考图】
图像1仅作为粗圆手绘线、扁平童话造型、复古粉质色彩和纸张肌理参考。不要复制人物、狗、悬崖、太阳、文字或原构图。不要生成实体卡牌。

【目标与格式】
原创、正面、平视、满版2:3竖版插画；不要牌名、编号、文字、logo或水印。不判断开门或关门哪一个正确。

【场景】
人物站在普通房间的半开门内侧，一只手靠近门把但没有握紧，另一只手自然垂下。门外地面放着一件普通物品，例如折好的围巾或小包；更远处只见另一道模糊但姿态中性的身影。门内外光线接近，门框结实但不厚重。

【双义性】
人物可能正在开门、关门或维持现在的距离。门外的人可能等待、离开或刚刚到来；物品可能是归还、交付或暂存。边界可以保护，也可能需要说明。

【构图与限制】
门缝、门把附近的手和门外物品形成中心。不要门内天堂、门外黑暗、锁链、监狱门、威胁身影、求救姿态、权威王座、发光门缝、传统皇帝符号、摄影、3D或写实室内设计。
```

## V. 借来的外套 / The Borrowed Coat

**原型来源：** 教皇——辨认继承的规则、角色与群体期待，并决定哪些真正适合自己。

**核心张力：** 当前承担的责任来自自己的价值选择，还是来自未经检查的外部期待？

**Tender（内部）：** 接受群体规则和他人期待，可能曾带来归属、安全或方向。

**Fierce（内部）：** 是否可以保留合身的部分，并退回或调整不属于自己的角色？

```text
【参考图】
图像1只作为粗圆轮廓、扁平民间故事造型、复古套色、彩铅水粉颗粒和暖纸底参考。不要复制参考图人物、服装设计、狗、手杖、太阳、文字或构图。不要生成实体卡牌。

【目标与格式】
原创、正面、平视、满版2:3竖版插画；无牌名、编号、文字、logo和水印。不把任何外套编码成好或坏。

【场景】
一名人物站在公共衣帽间或门厅，肩上披着一件略大的普通外套，袖口稍长但仍能保暖。墙上还挂着两件尺寸和材质不同的外套；画面边缘一只手托着另一件折好的外套，停在交接之前。人物自己的薄衣仍可见，一只手放在外套领口，像在判断是否合身。

【双义性】
外套可能是帮助、传统、职责或临时借用。略大不代表必须退回，保暖也不代表必须一直穿着。人物可以接受、调整、替换或归还，但没有标准答案。

【构图与限制】
人物、肩上外套和尚未完成的交接为中心。不要制服徽章、宗教服饰、姓名标签、身份文字、审判人群、权威高台、传统教皇手势、神圣光环、摄影、3D。色彩差异不能表示道德高低或所有权。
```

## VI. 桌子中间 / The Middle of the Table

**原型来源：** 恋人——关系、价值一致性和需要双方参与的选择。

**核心张力：** 关系中的靠近、承诺或决定，是出于诚实选择，还是出于害怕冲突与失去？

**Tender（内部）：** 犹豫可能来自珍惜关系，而不是缺乏勇气。

**Fierce（内部）：** 是否能让双方需要和自己的价值都被清楚看见，再作出选择？

```text
【参考图】
图像1仅用于粗圆手绘线、扁平童话造型、柔和复古色、粉质颗粒和纸张纹理。不要复制原人物、狗、悬崖、太阳、文字或构图。不要生成实体卡牌样机。

【目标与格式】
原创、正面、平视、满版2:3竖版插画；无牌名、编号、文字、logo或水印。不要把任何一方画成正确、受害或控制者。

【场景】
两名年龄不明确、五官极少的人坐在同一张普通桌子的两侧。每人面前各有一只杯子和一件个人物品。桌子正中放着一个小木盒和一把普通钥匙，两人的手都靠近桌面，但都没有触碰中央物品。两把椅子距离相近，人物姿态开放但并不亲密夸张。

【双义性】
中央物品可能代表共同决定、共享责任或需要协商的安排。两人可能准备靠近、暂停、分开处理或提出不同方案。无法判断他们是否意见一致，也不要求关系必须继续。

【构图与限制】
两人、中央物品和未触碰的手保持平衡构图。不要婚礼、心形、情侣刻板印象、天使、裸身人物、命定红线、浪漫光芒、争吵表情、法庭或传统恋人牌构图。使用温暖复古色，但双方色彩权重相等。
```

## VII. 可转向的车 / The Cart That Can Turn

**原型来源：** 战车——选择方向、承担行动，同时保留调整控制的能力。

**核心张力：** 坚定前进是在服务重要目标，还是原计划已经变成不能修正的要求？

**Tender（内部）：** 改变路线不等于缺乏纪律或失败。

**Fierce（内部）：** 是否可以先选一个方向，并设定能够观察和调整的节点？

```text
【参考图】
图像1只用于粗圆手绘线、扁平童话比例、复古套色、彩铅水粉质感和暖纸底。不要复制人物、动物、悬崖、太阳、文字或构图。不要生成卡牌照片。

【目标与格式】
原创、正面、平视、满版2:3竖版插画；不要牌名、编号、文字、logo或水印。画面不暗示某条路线必然正确。

【场景】
人物推着一辆装有少量固定货物的双轮小车来到一处宽缓弯道。小车前轮或转向杆明显能够改变方向，人物双手仍握在可调整的位置，没有加速冲刺。道路一侧有可短暂停靠的平地，另一侧继续缓慢转弯；两边路况相近。

【双义性】
人物可以继续、转弯、停靠或重新固定货物。车上的负载可能值得继续运送，也可能需要重新安排。转向是能力，不是退缩；前进也不代表必须坚持到底。

【构图与限制】
人物、转向结构和弯道为中心。不要战马、盔甲、胜利游行、黑白动物、箭头、终点旗帜、发光道路、悬崖、速度线、传统战车符号、摄影或3D。保持手绘温度和同等路线光线。
```
