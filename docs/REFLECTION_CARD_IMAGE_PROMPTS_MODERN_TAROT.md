# 22张反思卡：明亮象牙纸线描水彩生图文本

本文件以已经确定的“未定之步”成图作为整套视觉基准，供 Image 2 生成其余21张卡牌。它保留现有卡牌名称、核心张力和图像锚点，不修改应用中的抽卡、反思或LLM逻辑。

## 使用顺序

1. “未定之步”已经是基准卡，无需重新生成；下面保留它的成图描述，供检查整套一致性。
2. 生成其余21张牌时，每次只生成一张，并将“未定之步”成图上传为“图像1”。
3. 复制对应卡牌的整个 `text` 代码块，不要只复制场景段落。
4. 初次生成使用2:3竖版。若结果接近目标，下一轮只修改一个问题，并重新强调不能改变的部分。
5. 图像1只控制线条、纸张、罩染、色彩、人物简化程度和边框；不得把“未定之步”的人物、背包、踏石、雾或构图复制到其他卡。

## 整套统一视觉规则

- 视觉方向：明亮暖象牙白纸上的复古线描水彩卡牌，清新、安静、通透，略带童话故事感但不过度可爱。
- 线条：清楚的深褐手绘墨线，粗细有轻微变化；人物与主要物体轮廓较明确，远景和雾中细节更轻、更淡。
- 形体：写实基础上的适度简化；人物略带故事书比例、五官极少，不使用Q版大头或动漫五官。
- 质感：透明水彩与细腻彩铅纹理叠加，象牙白纸底清楚透出；保留均匀纸张颗粒、柔和颜料边缘和轻微手工印刷感，但不做泛黄、污渍或做旧磨损。
- 色板：清浅天蓝、雾白、清新的鼠尾草绿与橄榄绿、沙米色和暖棕为主；只用少量明净蓝色、柔黄或低饱和陶土红作现实物件点缀。
- 明度：整体高明度、低至中等对比；空气和背景留有大面积浅蓝与雾白呼吸空间，暗部仅用透明褐灰，不使用纯黑大色块、强烈聚光或阴暗电影调色。
- 版式：暖象牙白纸边加简洁深褐双线内框，四角轻微内收；边框清楚稳定但保留少量手绘感，无标题栏、编号、文字或徽记。
- 含义：每张牌只有一个主要动作或状态、少量现实线索和一个未完成选择。
- 人物：根据可读性选择完整人物、局部动作或无人物空间；人物牌沿用基准图的故事书式简化比例，无人物牌也必须保留一个清楚的现实事件或未完成状态。
- 禁止：传统大阿卡纳符号、善恶色码、发光答案、鲜艳现代平涂、日系动漫、Q版萌系、厚重油画、摄影、3D、光滑矢量、数字喷枪或黑暗哥特。

## 生成后逐张检查

- 是否能在一秒内说出画面中的普通物件或动作？
- 不知道牌名和原型的人，是否能用一句话说出“这里正在发生什么”？
- 是否只保留一个主要动作或状态？
- 主要关系在手机缩略图尺寸下是否仍然可见，而不是依赖针脚、纽扣或水位等微小细节？
- 双义性是否来自一个尚未完成的现实动作，而不是要求用户猜测物体象征什么？
- 是否同时存在至少两种合理解释，而不是“正确路”和“错误路”？
- 是否没有传统大阿卡纳符号、牌名、编号、文字、logo或水印？
- 人物是否与“未定之步”的简化程度一致，而不是Q版、动漫化或过度写实？
- 无人物牌是否仍有明确现实用途，而不是只剩抽象象征？
- 边框、线条、纸张颗粒和色板是否与整套保持一致？
- 若第一版接近目标，下一轮是否只修改一个问题？
