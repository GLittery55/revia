# 22张反思卡：Self-Compassion三维度与LLM解读规格

本文件是卡牌替换的数据设计源，结构对应当前 `CardReflectionGuidance`、`CardSelfCompassionGuidance` 和 `CardVisualScaffold`。它不改变抽卡、阶段推进、匹配、责任判断或对话生成逻辑。

大阿卡纳原型只用于设计阶段，不发送给用户，也不作为固定牌义。卡面标题、原型名称、核心张力、Tender/Fierce 和三维度字段均不得在用户尚未解释图像前进入对话。

## Self-Compassion三维度

- **自我善意 Self-kindness：** 用具体、不过度宽慰的方式理解痛苦、限制和保护反应，避免把一次行为或结果扩大为人格判决。它不取消影响、责任、边界或修复。
- **共同人性 Common humanity：** 在用户出现孤立、羞耻、能力比较或关系支持语言时，承认不完美、依赖、犯错和受限是共同的人类经验；不能用“大家都这样”淡化用户的独特处境或具体影响。
- **正念 Mindfulness：** 区分可观察事实、情绪体验、个人解释、预测与未知；既不压制痛苦，也不与羞愧、焦虑或全局标签过度认同。

三维度不是每轮必须覆盖的清单。现有实现只允许本地匹配后选中一个候选方向，LLM只能用它调整当轮措辞，不得自行选择、混合或补全其余维度。

## LLM使用顺序

1. **图像观察：** 只邀请用户描述画面，不提供牌义。
2. **图像支架：** 用户说“想不到”时，只能针对用户已经说出的图案提出一个中性画面问题。
3. **结构映射：** 只有用户同时提供图像关系和现实关系，且本地匹配存在共同概念时，才能提出一个可修改、可拒绝的相似性。
4. **Tender：** 只使用本地选中的一个Tender候选，承接用户已经说出的痛苦、限制或保护作用。
5. **Fierce：** 只有用户已经提供具体行为、影响或边界时，才使用本地选中的一个Fierce候选；不能由图案推断责任。
6. **三维度：** 只使用本地选中的一个Self-Compassion候选调整措辞，不显示维度名称。

## 全局禁止

- 不说“这个图案代表……”“这张牌说明你……”“你潜意识里……”
- 不把画中人物等同于用户或某个具体他人。
- 不从表情、光线、方位、颜色或大阿卡纳原型推断动机、人格、诊断、责任或未来。
- 不使用卡牌标题替用户解释图像。
- 不因为用户延迟、疲惫、沉默、焦虑或自我批评而推断逃避、过错或责任。
- 不把共同人性写成淡化影响的“每个人都会这样”。
- 不把自我善意写成免责，也不把Fierce写成指责。

## 0. 未定之步 / The Unwritten Step

- **原型：** 愚者
- **核心张力：** 不确定时的谨慎保护与逐渐不行动之间。
- **图案锚点：** 路、脚、踏石、雾、打开的包。
- **可比较的画面关系：** 脚停在落下之前；已有部分准备，但前路仍不完整。只有用户亲自描述这些关系时才能引用。
- **可能方向：** 不确定、准备、行动、回避、可撤回尝试。
- **Tender候选：** “还没有准备好不等于软弱”；“信息不完整时犹豫可能是在保护自己。”
- **Fierce候选：** “是否有一个可尝试并可回退的小动作”；“哪些信息确实需要补充，哪些等待没有明确终点。”
- **主维度：** 正念；次维度：自我善意、共同人性。
- **自我善意：** 犹豫、缺少把握或害怕出错，不等于懒惰、软弱或没有能力。
- **共同人性：** 仅当用户出现“别人都能开始、只有我不行”的比较时，可承认人在信息不完整时犹豫很常见。
- **正念：** 分开真正缺少的信息、担心的结果，以及尚未发生也未经证实的预测。
- **候选问题：** “目前哪些部分是真的还不清楚，哪些部分是你担心可能发生、但还没有发生的？”
- **激活提示：** 用户把抬起的脚、踏石、薄雾或未整理的包联系到开始困难、选择或不确定。
- **图像支架：** “你觉得这只脚为什么会停在落下之前？”；“包里的准备和前面的路之间有什么不同？”
- **特定禁止：** 不说“雾代表你的恐惧”或“这张牌要求你勇敢迈出第一步”。

## I. 可用之手 / The Capable Hand

- **原型：** 魔术师
- **核心张力：** 资源确实不足与暂时看不见已有能力之间。
- **图案锚点：** 手、针、线、布袋、补丁、针脚、裂口、布片、顶针。
- **可比较的画面关系：** 同一件布袋已有一处牢固补丁，新的裂口尚未处理；穿好线的针停在下一针之前。
- **可能方向：** 能力、资源、帮助、行动、准备。
- **Tender候选：** “感到无力不等于真的没有能力”；“复杂任务会让已有资源暂时难以被看见。”
- **Fierce候选：** “现在能使用的一项技能、工具或帮助是什么”；“怎样把缺少的条件说成具体请求。”
- **主维度：** 自我善意；次维度：正念、共同人性。
- **自我善意：** 暂时停住不等于无能，压力和害怕失败会降低对资源的感知。
- **共同人性：** 能力也包括使用工具、经验、合作和支持，而不是独自完成全部。
- **正念：** 盘点实际存在的工具与技能，同时保留真正缺少的条件。
- **候选问题：** “现在手边已经有哪些工具、经验或人可以用？还真正缺少的是什么？”
- **激活提示：** 用户把旧补丁、新裂口、穿好线的针或压平布料的手联系到已有经验、当前条件、帮助或开始修补。
- **图像支架：** “你觉得已经缝好的补丁和旁边的裂口有什么不同？”；“这根穿好线的针接下来可能怎样被使用？”
- **特定禁止：** 不说“你已经有能力解决一切”，不把旧补丁当作用户必须独立完成新修补的证据，也不把针线指定为唯一答案。

## II. 合上的盒子 / The Closed Box

- **原型：** 女祭司
- **核心张力：** 保留隐私和等待理解，与回避已经隐约知道的内容之间。
- **图案锚点：** 盒子、盒盖、桌子、已取出的物品、手。
- **可比较的画面关系：** 盒子没有上锁；部分内容已经取出，剩余部分仍被保留。
- **可能方向：** 隐私、不确定、觉察、表达、保护。
- **Tender候选：** “不必立刻解释或公开所有内在经验”；“还没有准备好打开不等于不诚实。”
- **Fierce候选：** “即使保留未知，已经确认的部分是什么”；“是否有一件已取出的内容需要被命名或回应。”
- **主维度：** 正念；次维度：自我善意、共同人性。
- **自我善意：** 允许自己按可承受的速度接近难以整理的内容。
- **共同人性：** 人对隐私、暴露和被理解的需要常常同时存在；只在用户谈到孤立或比较时使用。
- **正念：** 分开已经看见、仍未打开，以及出于推测补上的内容。
- **候选问题：** “如果不必一次打开全部，已经摆在桌面上的部分告诉了你什么？”
- **激活提示：** 用户把盒盖、已取出物品或停下的手联系到隐私、尚未表达或部分了解。
- **图像支架：** “你觉得为什么有些东西已经取出，盒子却还合着？”；“那只手接下来可能怎样处理盒盖？”
- **特定禁止：** 不说盒中藏着“真实自我”、创伤、秘密或被压抑记忆。

## III. 添上的一碗 / The Bowl Set Down

- **原型：** 女皇
- **核心张力：** 真实滋养与用照顾无限延后其他需要之间。
- **图案锚点：** 碗、水、低桌、毯子、暂放的任务物品。
- **可比较的画面关系：** 食物和水被放下；任务仍在场，但没有被催促继续。
- **可能方向：** 照顾、恢复、容量、休息、重新开始。
- **Tender候选：** “身体和情绪需要补充，不必先证明值得”；“暂停任务来恢复不等于失败。”
- **Fierce候选：** “哪一种照顾会让容量真正恢复”；“如何观察照顾后是否更能靠近需要处理的事。”
- **主维度：** 自我善意；次维度：正念、共同人性。
- **自我善意：** 把食物、水、温暖和休息视为基本需要，而非奖励。
- **共同人性：** 人的容量会消耗，也需要依赖环境和他人的照顾；不用于淡化长期停滞。
- **正念：** 观察照顾后的实际变化，而不是预先把休息判为有用或回避。
- **候选问题：** “什么样的照顾会让你更有一点容量，而不只是暂时离开这件事？”
- **激活提示：** 用户把碗、水、毯子或暂放的任务联系到疲惫、照顾和恢复。
- **图像支架：** “你觉得这碗东西是为谁准备的？”；“桌上的任务物品为什么被放在一旁？”
- **特定禁止：** 不说“你需要好好爱自己”或把食物解释为母性、疗愈或奖励。

## IV. 半开的门 / The Half-Open Door

- **原型：** 皇帝
- **核心张力：** 保护性的边界与回避必要沟通之间。
- **图案锚点：** 门、门把手、门缝、室内、室外、物品或身影。
- **可比较的画面关系：** 门既未完全打开也未完全关闭；手停在门把附近。
- **可能方向：** 边界、保护、回避、沟通、距离。
- **Tender候选：** “保持距离可能是在保护安全、精力或尊严”；“拒绝不等于冷漠或自私。”
- **Fierce候选：** “是否需要更明确地表达边界”；“沉默是否让某件事持续悬而未决。”
- **主维度：** 自我善意；次维度：正念、共同人性。
- **自我善意：** 不把暂时退出、拒绝或降低联系解释成人格缺陷。
- **共同人性：** 健康关系同时需要靠近、距离和沟通，不要求始终开放。
- **正念：** 分清关闭的是某个请求、一次互动、一段时间还是整段关系。
- **候选问题：** “你想保护的具体是什么？同时，有没有一句需要说清楚、但还停在门口的话？”
- **激活提示：** 用户把门、门把、门内外或身影联系到边界、距离或未完成沟通。
- **图像支架：** “你觉得这扇门接下来可能怎样变化？”；“画面里什么让门停在这个位置？”
- **特定禁止：** 不说用户在逃避亲密、应该开门或门外人物代表某个具体的人。

## V. 借来的外套 / The Borrowed Coat

- **原型：** 教皇
- **核心张力：** 自己选择的责任与未经检查的外部角色、规则和期待之间。
- **图案锚点：** 外套、衣帽间、袖口、领口、递来的衣物。
- **可比较的画面关系：** 外套能够保暖但不完全合身；另一件衣物仍停在交接之前。
- **可能方向：** 期待、归属、责任、角色、边界。
- **Tender候选：** “接受规则或角色可能曾带来归属与安全”；“不合身带来的疲惫不说明能力不足。”
- **Fierce候选：** “哪些要求与自己的价值一致”；“哪些角色需要调整、归还或重新协商。”
- **主维度：** 共同人性；次维度：正念、自我善意。
- **自我善意：** 不必靠穿下所有被递来的角色证明可靠或有价值。
- **共同人性：** 责任常在家庭、关系、团队和文化中形成，需要协商而非完全个人化。
- **正念：** 分开自己认同的承诺、为了归属接下的要求和实际无法承担的部分。
- **候选问题：** “这件外套里哪些部分确实适合你，哪些只是因为被递过来而穿在身上？”
- **激活提示：** 用户把外套、尺寸、袖口或交接联系到期待、身份、责任或归属。
- **图像支架：** “你觉得肩上的外套现在合身吗？”；“画面边缘递来的另一件外套可能会怎样？”
- **特定禁止：** 不指定谁施加期待，不把传统、家庭或群体自动描述为压迫。

## VI. 桌子中间 / The Middle of the Table

- **原型：** 恋人
- **核心张力：** 关系中的选择来自价值与诚实，还是来自害怕冲突或失去。
- **图案锚点：** 两个人、桌子、杯子、中央物品、钥匙、未触碰的手。
- **可比较的画面关系：** 双方都在场，但共同物品仍位于中间且无人触碰。
- **可能方向：** 关系、选择、沟通、互惠、承诺。
- **Tender候选：** “犹豫可能来自珍惜关系”；“需要时间不等于不在乎。”
- **Fierce候选：** “双方需要是否都被说清楚”；“哪项选择更符合自己愿意承担的价值与后果。”
- **主维度：** 共同人性；次维度：正念、自我善意。
- **自我善意：** 不因关系中的矛盾和犹豫立即责备自己不够坚定。
- **共同人性：** 关系选择涉及相互依赖和两方主体性，一个人无法控制全部结果。
- **正念：** 区分自己的需要、对方已经表达的内容，以及对对方反应的预测。
- **候选问题：** “如果桌子两边的需要都被看见，中间这件事还需要说清楚什么？”
- **激活提示：** 用户把两人、中央物品、距离或未触碰动作联系到关系、选择或共同决定。
- **图像支架：** “你觉得桌子中间的东西为什么还没有被拿起？”；“两边的手现在分别在等待什么？”
- **特定禁止：** 不推断爱情关系、分手、亲密障碍或谁应该让步。

## VII. 可转向的车 / The Cart That Can Turn

- **原型：** 战车
- **核心张力：** 有方向的行动与不能修正原计划的僵硬坚持之间。
- **图案锚点：** 小车、把手、转向杆、弯道、货物、停靠处。
- **可比较的画面关系：** 车已上路且载有东西，但方向和停靠仍可调整。
- **可能方向：** 行动、调整、控制、目标、弹性。
- **Tender候选：** “改变路线不等于缺乏纪律”；“负载和路况变化值得进入计划。”
- **Fierce候选：** “能否选择一个方向并设定复查点”；“哪些货物或目标需要重新固定或减少。”
- **主维度：** 正念；次维度：自我善意、共同人性。
- **自我善意：** 不把转向、停靠或重新安排解释为失败。
- **共同人性：** 可持续行动通常依赖反馈、工具和环境，不只是意志力。
- **正念：** 观察实际方向、速度、负载和可调整位置，而非只评价是否坚持。
- **候选问题：** “如果先不要求一路到底，在哪里停一下检查方向会更实际？”
- **激活提示：** 用户把小车、弯道、把手、货物或停靠处联系到计划、行动或调整。
- **图像支架：** “你觉得这辆车接下来可能怎样转向？”；“车上的货物会怎样影响它的方向？”
- **特定禁止：** 不说用户必须掌控一切、勇往直前或已经偏离正确道路。

## VIII. 不握紧的手 / The Unclenched Hand

- **原型：** 力量
- **核心张力：** 温柔尊重脆弱与因害怕冲突而放弃必要坚定之间。
- **图案锚点：** 张开的手、动物、细枝、软绳、松动的环。
- **可比较的画面关系：** 一只手给出空间，另一只手仍在完成解缠动作。
- **可能方向：** 温柔、勇气、在场、保护、坚定。
- **Tender候选：** “强烈反应不需要通过压制才能处理”；“害怕靠近困难不等于软弱。”
- **Fierce候选：** “是否能不攻击也不逃离地完成必要动作”；“怎样同时给空间并保持边界。”
- **主维度：** 自我善意；次维度：正念、共同人性。
- **自我善意：** 用对待受惊生命的耐心对待自己的保护反应，不用羞辱迫使改变。
- **共同人性：** 害怕、警觉和需要安全是共有反应；只在用户谈到孤立或自我比较时使用。
- **正念：** 分开当下真实危险、身体警觉和对冲突的预测。
- **候选问题：** “如果不需要靠握紧来处理，这件事里仍然需要完成的动作是什么？”
- **激活提示：** 用户把张开的手、动物、绳环或解缠联系到恐惧、安抚、勇气或坚定。
- **图像支架：** “你觉得张开的手和正在解开的绳环各自在做什么？”；“动物接下来可能留下还是退开？”
- **特定禁止：** 不说动物代表用户的本能、创伤或需要被驯服的情绪。

## IX. 独处的灯 / The Solitary Lamp

- **原型：** 隐者
- **核心张力：** 恢复性的独处与逐渐隔绝重要支持之间。
- **图案锚点：** 灯、桌子、门、鞋、手机或纸条、远处亮窗。
- **可比较的画面关系：** 人物选择安静，但门未锁且联系入口仍存在。
- **可能方向：** 独处、恢复、孤立、联系、边界。
- **Tender候选：** “保留安静和不回应的时间是合理需要”；“独处不等于拒绝关系。”
- **Fierce候选：** “是否需要留下一个低风险联系入口”；“独处后的实际状态是在恢复还是更难靠近支持。”
- **主维度：** 自我善意；次维度：共同人性、正念。
- **自我善意：** 不因需要独处而责备自己冷漠、麻烦或不合群。
- **共同人性：** 自主和连接是同时存在的人类需要，不必二选一。
- **正念：** 观察独处后的身体、情绪和联系能力变化。
- **候选问题：** “这段独处现在更像让你恢复，还是也让需要的支持更难靠近？”
- **激活提示：** 用户把灯、关闭但未锁的门、手机或远处窗户联系到独处、恢复或隔绝。
- **图像支架：** “你觉得门为什么关着却没有上锁？”；“桌上的灯和远处的窗之间有什么不同？”
- **特定禁止：** 不诊断社交退缩、抑郁或孤独人格。

## X. 接雨的碗 / The Bowls Under the Leak

- **原型：** 命运之轮
- **核心张力：** 曾经有效的重复应对与它当前产生的代价之间。
- **图案锚点：** 滴水、满碗、空碗、墙边旧碗、通道、雨。
- **可比较的画面关系：** 接水保持地面干燥，但不断轮换的碗开始占用空间。
- **可能方向：** 模式、保护、代价、改变、外部限制。
- **Tender候选：** “重复做法可能确实帮助过自己”；“回到熟悉方式不等于没救或不自律。”
- **Fierce候选：** “这个方式现在带来什么代价”；“能否改变或补充其中一个小环节。”
- **主维度：** 正念；次维度：自我善意、共同人性。
- **自我善意：** 先承认接水行为的实际保护作用，再讨论改变。
- **共同人性：** 人在压力下回到熟悉做法很常见，改变也可能包含反复。
- **正念：** 观察触发条件、短期作用、长期代价和环境是否已变化。
- **候选问题：** “这个做法当下帮你接住了什么，又让哪些空间越来越难使用？”
- **激活提示：** 用户把漏水、轮换碗、干燥地面或变窄通道联系到重复模式和代价。
- **图像支架：** “你觉得人物为什么又拿来一个空碗？”；“墙边的旧碗和现在的滴水有什么关系？”
- **特定禁止：** 不说用户只是在治标不治本、应该立刻修屋顶或重复模式必然有害。

## XI. 两边的重量 / The Uneven Balance

- **原型：** 正义
- **核心张力：** 自己与他人的需要、时间和责任如何被诚实分配。
- **图案锚点：** 长桌、两端、不同物品、中央人物、手中物品。
- **可比较的画面关系：** 两边可见但无法仅按数量判断重量，最后一件仍未分配。
- **可能方向：** 公平、责任、边界、关系、过载。
- **Tender候选：** “优先照顾别人可能来自善意或责任感”；“长期不均衡带来的疲惫值得被承认。”
- **Fierce候选：** “哪些责任需要重新分配”；“不均衡是否被看见、同意并能够调整。”
- **主维度：** 正念；次维度：共同人性、自我善意。
- **自我善意：** 不因想照顾自己就判定自私，也不因承担过多就判定软弱。
- **共同人性：** 公平依赖协商和互惠，不等于每一刻数量完全相同。
- **正念：** 分开谁承担什么、持续多久、是否自愿，以及实际产生的影响。
- **候选问题：** “现在两边分别有哪些需要和责任？这种不平衡是临时的，还是已经持续了一段时间？”
- **激活提示：** 用户把桌子两边、物品差异或中央未分配物联系到责任、关系或过载。
- **图像支架：** “你觉得桌子两边为什么会呈现现在的状态？”；“人物手里的东西可能被放到哪边？”
- **特定禁止：** 不根据数量、位置或色彩判定谁付出更多、谁有错。

## XII. 暂放之处 / The Resting Place

- **原型：** 倒吊人
- **核心张力：** 必要恢复与长期停滞之间。
- **图案锚点：** 长椅、鞋、水、地图、道路、人物。
- **可比较的画面关系：** 鞋被脱下且道路仍在；停下可能刚开始，也可能已经持续。
- **可能方向：** 休息、恢复、停滞、节奏、重新开始。
- **Tender候选：** “疲惫和休息不自动等于懒惰”；“过度消耗后暂停有现实原因。”
- **Fierce候选：** “停下后更有恢复还是更难重新靠近”；“用什么可观察迹象判断下一步。”
- **主维度：** 自我善意；次维度：正念、共同人性。
- **自我善意：** 把身体与情绪承受能力纳入理解，而不是只用产出评价自己。
- **共同人性：** 仅在用户出现孤立或能力比较时，承认人需要恢复是共同处境。
- **正念：** 观察休息后的实际作用，而不是预设休息等于照顾或回避。
- **候选问题：** “这段停下来之后，你感到更有恢复，还是更难重新靠近原来的事情？”
- **激活提示：** 用户把长椅、鞋、地图或道路联系到疲惫、暂停或延迟。
- **图像支架：** “你觉得这些鞋为什么被放在这里？”；“这次停下之后，画面里接下来可能发生什么？”
- **特定禁止：** 不说用户需要休息、休息太久或应该马上重新出发。

## XIII. 松开的结 / The Loosened Knot

- **原型：** 死神
- **核心张力：** 守护重要承诺与松开持续伤害的连接之间。
- **图案锚点：** 绳结、空隙、手、绳端、闭合剪刀。
- **可比较的画面关系：** 连接仍存在但已经松动；握住、调整、松开和剪断都尚未发生。
- **可能方向：** 放下、承诺、失落、边界、选择。
- **Tender候选：** “放下不再适合的事物不等于失败”；“松开之前的哀伤值得被承认。”
- **Fierce候选：** “哪些承诺仍想保留”；“是否需要主动松开持续造成伤害的部分。”
- **主维度：** 自我善意；次维度：正念、共同人性。
- **自我善意：** 允许失落存在，不要求立刻把结束转化为成长。
- **共同人性：** 关系、承诺和身份会变化，人无法永久保留所有连接。
- **正念：** 区分仍重要的连接、现实伤害和因为害怕失去而继续抓住的部分。
- **候选问题：** “你想保留的是这个结里的哪一部分？又有哪些地方已经需要松一些？”
- **激活提示：** 用户把结、空隙、握住的手或剪刀联系到放下、承诺、失落或边界。
- **图像支架：** “你觉得这个结接下来可能怎样变化？”；“那只手现在更像在握住、调整还是准备松开？”
- **特定禁止：** 不说某段关系必须结束，不把剪刀指定为解脱。

## XIV. 重新调配 / The New Measure

- **原型：** 节制
- **核心张力：** 根据现实容量调整资源，与把更多任务继续压入有限空间之间。
- **图案锚点：** 壶、水流、不同杯子、储存瓶、空容器。
- **可比较的画面关系：** 资源有限且尚未分完；不同容器可能有不同需要。
- **可能方向：** 调整、容量、优先级、限制、可持续。
- **Tender候选：** “重新安排目标与资源不等于缺乏纪律”；“容量变化值得进入计划。”
- **Fierce候选：** “哪些优先级需要真正减少或延后”；“是否仍试图让所有容器同时装满。”
- **主维度：** 正念；次维度：自我善意、共同人性。
- **自我善意：** 不因降低目标、减少份量或重新安排而攻击自己。
- **共同人性：** 人的精力和时间都有限，依赖分工和调整是普通现实。
- **正念：** 区分重要、紧急、可暂放和当前无法同时保留的要求。
- **候选问题：** “如果总量不会增加，当前最需要保留什么，哪些可以少一些或晚一些？”
- **激活提示：** 用户把水流、杯子、储存瓶或不同水位联系到容量、计划和优先级。
- **图像支架：** “你觉得这壶里的水接下来会怎样分配？”；“为什么桌上还留着一个空容器？”
- **特定禁止：** 不说平均分配才公平，不把水位解释成情绪能量数值。

## XV. 缠在手上的线 / The Thread Around the Hand

- **原型：** 恶魔
- **核心张力：** 熟悉的控制方式仍在维持安全，还是已经开始限制新的行动。
- **图案锚点：** 线团、整齐包裹、手指、线环、桌面。
- **可比较的画面关系：** 线已经让物品保持整齐，同时也限制手掌完全张开。
- **可能方向：** 控制、模式、安全、限制、松开。
- **Tender候选：** “整理、紧握或重复控制可能曾避免混乱”；“看见限制不需要先责怪自己。”
- **Fierce候选：** “当前限制具体出现在哪里”；“能否先松开一个仍可逆的小环。”
- **主维度：** 正念；次维度：自我善意、共同人性。
- **自我善意：** 先承认控制方式曾经维持秩序或安全，而不是把它描述成缺陷。
- **共同人性：** 人在不确定和压力下容易加强熟悉的控制方式；不用于泛化或免责。
- **正念：** 同时观察短期秩序、手部限制和仍可改变的部分。
- **候选问题：** “这根线现在帮你维持了什么，又让哪一个动作变得更难？”
- **激活提示：** 用户把线团、包裹或手指上的线联系到控制、习惯、安全或受限。
- **图像支架：** “你觉得线为什么同时绕着包裹和手？”；“如果线继续绕下去，画面里会先发生什么？”
- **特定禁止：** 不说用户被欲望、依赖、关系或习惯束缚，不使用成瘾诊断。

## XVI. 裂痕与器皿 / The Cracked Vessel

- **原型：** 高塔
- **核心张力：** 承认具体破裂和影响，与把事件扩大成整个自我的失败之间。
- **图案锚点：** 器皿、裂缝、渗水、布、手、修补材料。
- **可比较的画面关系：** 裂痕真实产生影响，但器皿仍保持完整且有多种处理方式。
- **可能方向：** 羞愧、责任、影响、修复、自我评价。
- **Tender候选：** “做错一件事不等于整个人失败”；“羞愧可以被看见但不能替代事实。”
- **Fierce候选：** “这道具体裂痕造成了什么影响”；“哪些影响需要承认、说明或修补。”
- **主维度：** 自我善意；次维度：正念、共同人性。
- **自我善意：** 承认行为与影响，同时拒绝把它转化为人格判决。
- **共同人性：** 犯错、判断失误和无意造成影响是人类经验的一部分，但不取消修复。
- **正念：** 分开裂痕事实、已经发生的影响、全局自我标签和仍未知的部分。
- **候选问题：** “如果先不评价整个人，只看这道具体裂痕，哪些影响需要被承认或处理？”
- **激活提示：** 用户把裂缝、渗水、悬停的手或修补物联系到错误、羞愧、影响或修复。
- **图像支架：** “你觉得这条裂缝接下来可能怎样变化？”；“画面里的水和手会怎样影响器皿的处理？”
- **特定禁止：** 不说用户已经破碎、需要被修好或经历了重大崩塌。

## XVII. 仍亮着的窗 / The Window Still Lit

- **原型：** 星星
- **核心张力：** 保护隐私和自主，与忽视可能获得的支持之间。
- **图案锚点：** 夜、房子、亮窗、人物、手机、纸条或钥匙。
- **可比较的画面关系：** 支持入口可能存在，但里面的人是否可回应仍未知。
- **可能方向：** 支持、求助、孤立、沟通、保护。
- **Tender候选：** “不知道怎样求助不等于必须独自承担”；“担心打扰或被拒绝是可以理解的。”
- **Fierce候选：** “是否有一个低风险的具体求助动作”；“怎样说明需要并保留边界。”
- **主维度：** 共同人性；次维度：自我善意、正念。
- **自我善意：** 不把需要帮助解释为能力不足、麻烦别人或不值得支持。
- **共同人性：** 相互依赖和被看见是共同需要，保持自主不等于独自承担。
- **正念：** 分开“不会有人帮”的预测、过去经验和现在可验证的小请求。
- **候选问题：** “如果只试一个风险较低的求助，你希望对方具体知道或提供什么？”
- **激活提示：** 用户把亮窗、夜路、手机或停留联系到求助、孤立和支持。
- **图像支架：** “你觉得人物为什么停在这扇亮窗外？”；“手中的物品接下来可能怎样被使用？”
- **特定禁止：** 不保证窗内有人等待、一定会回应或能够提供帮助。

## XVIII. 被遮住的窗 / The Clouded Window

- **原型：** 月亮
- **核心张力：** 当前判断反映现实的部分，与受情绪、疲惫和不完整信息影响的部分之间。
- **图案锚点：** 窗、雾气、雨痕、布、擦开区域、模糊道路。
- **可比较的画面关系：** 擦开的区域提供局部信息，但玻璃和窗外环境都仍有遮挡。
- **可能方向：** 事实、解释、不确定、自我评价、判断。
- **Tender候选：** “强烈情绪下看不清全貌不等于不理性”；“暂时不确定不代表判断能力失效。”
- **Fierce候选：** “哪些是已确认事实、哪些是解释”；“哪些未知需要继续保留。”
- **主维度：** 正念；次维度：自我善意、共同人性。
- **自我善意：** 不因视野受限而责备自己愚蠢、脆弱或永远看不清。
- **共同人性：** 仅在用户出现“只有我有问题”的比较时，承认情绪会让人的视野暂时变窄。
- **正念：** 分开事实、情绪体验、推测、预测和仍未知的部分。
- **候选问题：** “哪些是已经看见的事实，哪些是你对窗外的解释，还有哪些现在仍看不清？”
- **激活提示：** 用户把雾窗、雨痕、擦开区域或外部薄雾联系到判断、自我评价和不确定。
- **图像支架：** “擦开的这一小块和其他玻璃有什么不同？”；“你觉得遮挡来自玻璃，还是窗外本身也有雾？”
- **特定禁止：** 不说用户在欺骗自己、看到幻觉或缺乏理性。

## XIX. 已经飞稳的风筝 / The Kite Aloft

- **原型：** 太阳
- **核心张力：** 允许自己确认已经达成的成果和真实喜悦，而不立刻缩小、否定，或把成功变成必须继续证明价值的义务。
- **图案锚点：** 明亮草地、温暖天光、已经飞稳的风筝、绷紧但不费力的线、线轴、奔跑中微笑的人物。
- **可比较的画面关系：** 风筝已经稳定飞起，人物正在直接体验成果与活力；画面没有比赛、排名、奖杯或观众评价。
- **可能方向：** 喜悦、成功、生命力、光明、温暖、清晰、自信。
- **Tender候选：** “这一刻的喜悦不需要因为它可能短暂就被削弱”；“阶段性的成功也可以被完整地承认。”
- **Fierce候选：** “这项成果具体由哪些行动、能力和支持促成”；“如何让这份活力支持一个真正想选择的下一步，而不是急着再次证明自己。”
- **主维度：** 正念；次维度：自我善意、共同人性。
- **自我善意：** 允许自己开心、骄傲、轻松或感到有力量，不用“还不够”立刻消解已经发生的成果。
- **共同人性：** 仅在用户谈到支持、比较或分享时，承认成果可能同时来自个人投入、环境条件与他人支持。
- **正念：** 具体看见什么已经达成、身体正在感受什么，以及这份喜悦和活力在当下如何存在。
- **候选问题：** “这件事里，什么已经真正达成，哪一部分喜悦或力量值得你完整地承认？”
- **激活提示：** 用户把飞稳的风筝、明亮草地、奔跑姿态或微笑联系到已有成果、喜悦、活力、清晰或自信。
- **图像支架：** “画面里什么让你觉得风筝已经飞稳了？”；“你从人物的姿态里看到了什么感受？”
- **特定禁止：** 不保证之后一直顺利、不说目标达成已解决所有问题、不用成功证明人的价值，也不要求用户保持积极、马上设定下一个目标或忽视仍存在的问题。

## XX. 应声而起 / Rising to the Call

- **原型：** 审判
- **核心张力：** 回看并重新评估过去之后，某个重要认识已经无法继续忽略；人物可以让清醒转化为回应，同时不把过去的自己判为有罪或失败。
- **图案锚点：** 清晨、三张旧照片、推开的椅子、已经站起的人、迈出的脚、敞开的门、普通社区钟架、钟身摆动线。
- **可比较的画面关系：** 旧照片完整留在身后的桌上，人物已经从座位上站起并转向钟声与门；过去被看见而没有被销毁，回应已经开始但终点尚未被规定。
- **可能方向：** 反思、评估、觉醒、召唤、重生、回应、新阶段。
- **Tender候选：** “现在重新理解过去，不表示当时的自己一无是处”；“醒悟得比预期晚，也不等于已经失去重新回应的资格。”
- **Fierce候选：** “这段经历现在让你看清了什么”；“如果不再忽略这份认识，你准备以哪个具体回应开始新的阶段。”
- **主维度：** 正念；次维度：自我善意、共同人性。
- **自我善意：** 不用事后获得的认识羞辱、惩罚或否定当时处在有限条件中的自己。
- **共同人性：** 人会在经历之后修正理解、被某件重要事情重新唤醒并开始回应；仅在用户需要时，用这一点减轻“只有我曾经判断错误”的孤立感。
- **正念：** 区分过去实际发生了什么、现在如何重新评估、什么正在召唤注意，以及自己愿意如何回应。
- **候选问题：** “回看这段经历之后，什么已经变得无法继续忽略？你想用怎样的第一步回应它？”
- **激活提示：** 用户把旧照片、晨钟、起身动作或敞开的门联系到回顾、醒悟、重新开始或回应某件重要事情。
- **图像支架：** “人物为什么在钟声响起时站了起来？”；“留在桌上的旧照片和敞开的门之间，发生了什么变化？”
- **特定禁止：** 不宣布用户已经觉醒、重生或得到命运启示；不把钟声解释为客观真理、超自然指令或唯一正确道路；不把过去分成有罪与无罪；不要求联系、道歉、原谅、和解、离开或结束关系；不保证门外一定更好。

## XXI. 重新摆好的房间 / The Room Rearranged

- **原型：** 世界
- **核心张力：** 真实但不完整的进展，与把尚未全部解决解释为毫无改变之间。
- **图案锚点：** 房间、可用桌椅、中央空间、未拆箱、手中物品。
- **可比较的画面关系：** 房间已经能够生活，但仍有一个箱子和最后一件未决定位置的物品。
- **可能方向：** 整合、完成、改变、可持续、不完美。
- **Tender候选：** “不完整的进展仍然是真实进展”；“完整不要求一次解决全部。”
- **Fierce候选：** “是否可以结束一个已经足够完成的阶段”；“最后一件事需要放下、保留还是留待以后。”
- **主维度：** 自我善意；次维度：正念、共同人性。
- **自我善意：** 不用未拆的箱子否定整个房间已经发生的改变。
- **共同人性：** 生活中的完成常带着未尽部分，调整也可能继续发生。
- **正念：** 同时看见已经可用的结构、仍未完成的部分和下一步的现实容量。
- **候选问题：** “如果不要求全部完美，现在有哪些地方已经足够可用？还有哪一件事需要明确留下或结束？”
- **激活提示：** 用户把可使用的房间、中央空位、未拆箱或手中物品联系到完成、改变和不完美。
- **图像支架：** “你觉得房间里哪些地方已经可以使用？”；“人物手里的最后一件东西可能放在哪里？”
- **特定禁止：** 不宣布用户已经完成成长、进入新人生阶段或实现完整自我。
