# 22张反思卡：图像可读性审查

本审查以已经完成的“未定之步”为标杆。目标不是让图像直接讲出固定牌义，而是让没有塔罗背景的用户也能先描述一个具体场景、一个停住的动作，以及至少两种合理的下一步。

## 可读性标准

1. 缩小到手机卡面尺寸后，主要人物、物件与动作仍能辨认。
2. 用户不需要知道卡名、阿卡纳原型或象征意义，也能回答“这里正在发生什么？”
3. 画面只有一个主要事件；关键关系不依赖纽扣、针脚、水位等微小细节。
4. 双义性来自尚未完成的现实动作，而不是要求用户猜测物体象征什么。
5. 画面同时保留保护作用和改变可能，不把某一条路画成明显正确答案。
6. 不能仅凭颜色、表情、光线或位置判定人格、动机、责任和未来。

## 审查结果

| 编号 | 卡牌 | 结论 | 主要理由 |
|---|---|---|---|
| 0 | 未定之步 | 保留 | 人物、踏石、雾与背包构成清楚事件；停顿和下一步都容易描述。 |
| I | 可用之手 | 重设计 | 补丁、裂口、固定针和穿线针都太小，核心关系依赖近距离观察。 |
| II | 合上的盒子 | 重设计 | 无人物静物缺少正在发生的动作，容易只剩“盒子象征秘密”。 |
| III | 添上的一碗 | 保留 | 放下食物与暂停任务是熟悉的现实动作。 |
| IV | 半开的门 | 保留 | 门把上的手和半开状态能直接支持开、关或维持距离的叙述。 |
| V | 借来的外套 | 轻调 | 外套不合身容易看懂，但应减少衣帽间中的次要衣物。 |
| VI | 桌子中间 | 轻调 | 两人面对未触碰物品可读，但中央盒子与钥匙不宜同时出现。 |
| VII | 可转向的车 | 保留 | 人、车、弯道和停靠处构成清楚选择。 |
| VIII | 不握紧的手 | 重设计 | 只画手和动物前脚会像局部救援示意图，难理解双方位置。 |
| IX | 独处的灯 | 保留 | 无人房间仍有明确生活痕迹、边界和联系入口。 |
| X | 接雨的碗 | 保留 | 漏水、接水与被占用的通道形成可见的短期作用和长期代价。 |
| XI | 两边的重量 | 重设计 | 桌面两端的物品数量需要抽象比较，用户难以知道事件是什么。 |
| XII | 暂放之处 | 保留 | 脱鞋、长椅、地图与延伸道路构成清楚暂停。 |
| XIII | 松开的结 | 轻调 | 晾衣绳提供现实用途，但结必须足够大且仍能看见布被支撑。 |
| XIV | 重新调配 | 重设计 | 多个杯子与悬停水流过于寓言化，容易被读成平均分配测试。 |
| XV | 缠在手上的线 | 重设计 | 近景手部容易被直接读为受困或危险，缺少“线也在完成工作”的全景。 |
| XVI | 裂痕与器皿 | 保留 | 裂痕、渗水和未使用工具形成清楚影响与多种处理方式。 |
| XVII | 仍亮着的窗 | 保留 | 人物、手机与亮窗构成清楚的靠近、联系或离开选择。 |
| XVIII | 被遮住的窗 | 保留 | 擦开一小块窗户是明确动作，也自然保留局部事实与未知。 |
| XIX | 已经飞稳的风筝 | 已重设计 | 一个人、一只高处风筝和一条绷紧的线即可清楚表现目标达成、喜悦与生命力。 |
| XX | 应声而起 | 已重设计 | 旧照片、推开的椅子、已经站起的人和鸣响的晨钟形成清楚连续动作，同时表现回看、觉醒与回应。 |
| XXI | 重新摆好的房间 | 轻调 | 整体状态可读，但待放物必须足够醒目，避免像普通室内插画。 |

## 优先重设计

- **可用之手：** 改为路边自行车掉链、人物与打开的工具卷，突出“眼前已有一些资源，但是否足够仍未知”。
- **合上的盒子：** 加入人物正在触碰但尚未掀起盒盖的动作，让隐私与接近变成现实选择。
- **不握紧的手：** 拉远为人物蹲在被软绳缠住的动物旁，一手解绳、一手留出距离。
- **两边的重量：** 改为两人共同搬运一张长木板或长凳，货物偏向一端，双方暂停准备调整。
- **重新调配：** 改为容量有限的旅行篮与几件待选日用品，人物手里只拿着一件尚未决定放入的物品。
- **缠在手上的线：** 展示人物正在捆扎确实需要固定的包裹，同时线绕到手上，使帮助与限制同时可见。
- **太阳：** 改为“已经飞稳的风筝”，直接呈现已经发生的成果、温暖、喜悦和活力，不再使用多人多动作构图。
- **审判：** 改为“应声而起”，用回看旧照片、听见晨钟、从座位站起并转向敞开的门，同时呈现反思评估、召唤、觉醒回应与新阶段开始。

这些修改只用于视觉候选阶段。卡面确定并通过小规模解读测试前，不同步修改运行时标题、卡牌数据或LLM静态指导。
