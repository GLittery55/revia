# 22 张 Reflection Card 场景设计与 gpt-image-2 指令

本方案只依据两项输入：

1. 附件 Markdown 中 22 张大阿卡纳的内部内涵设计；
2. 《未定之渡.png》的画面风格。

没有沿用仓库内已有的卡牌场景、名称或提示词。下面的场景名只是制作代号，不是最终用户可见名称；卡面不得出现代号、原型名、编号或任何解释文字。

## 统一画面规则

从《未定之渡》提取的视觉语言：

- 2:3 竖幅，暖米白纸张底色，四周保留窄纸边和轻微不规则的深褐双线内框。
- 细密深褐墨线勾勒人物、木材、植物和日常器物，线条有手绘粗细变化。
- 透明水彩铺色叠加彩铅排线；可见细腻纸纹和轻微旧书印刷质感，但不做脏污、破损或重度泛黄。
- 高明度、低至中等对比；沙米色、暖棕、橄榄绿、鼠尾草绿、雾蓝、浅天蓝为主，少量柔黄和低饱和陶土红点缀。
- 自然、安静、通透，留出空气、天空或环境空间；不使用戏剧性聚光、纯黑阴影或善恶色码。
- 人物为现实比例上的轻度故事书简化，五官弱化，优先侧后方、背面或自然手部动作。
- 每张牌只画一个可直接描述的现实事件，并把动作停在决定发生之前。
- 场景必须允许至少两种合理解释；不能让光线、表情、视线、道路或颜色给出“正确答案”。
- 不出现传统塔罗符号、魔法、光环、命运箭头、牌名、编号、可读文字、logo、签名或水印。
- 不使用动漫、Q 版、摄影写实、3D、光滑矢量、厚重油画、暗黑哥特或数字喷枪质感。

## gpt-image-2 调用准备

以下命令使用项目内置的 ImageGen CLI，以《未定之渡》作为画风参考图。请在仓库根目录先执行：

```bash
export CODEX_HOME="${CODEX_HOME:-$HOME/.codex}"
export IMAGE_GEN="$CODEX_HOME/skills/.system/imagegen/scripts/image_gen.py"
export CARD_STYLE_REF="$PWD/BeyondComfort/Resources/card/未定之渡.png"
export CARD_OUTPUT_DIR="$PWD/output/imagegen/reflection-cards-new"
mkdir -p "$CARD_OUTPUT_DIR"

export CARD_BASE_PROMPT='输入图像1只作为视觉风格参考，不是编辑底图。请创作一个完全不同的新场景，不要复制参考图中的渡船、码头、旅行包、人物姿势、树木位置或构图。

创作原创、正面呈现的2:3竖版反思卡插画，不是实体卡牌照片或样机。继承参考图的暖米白纸张底色、窄纸边、轻微不规则的深褐双线内框、细密且有手绘粗细变化的深褐墨线、透明水彩铺色、细腻彩铅排线和轻微旧故事书印刷质感。整体高明度、低至中等对比，自然柔光，安静通透；色板以沙米色、暖棕、橄榄绿、鼠尾草绿、雾蓝和浅天蓝为主，只用少量柔黄与低饱和陶土红。人物若出现，采用现实比例上的轻度故事书简化，五官极少，年龄和性别不过度明确，动作自然；优先使用背面、侧后方或手部，不用夸张表情替观者解释。主要人物、物件和动作在手机缩略图尺寸下仍清楚。

画面只表现一个普通现实事件、少量必要线索和一个停在决定之前的动作。至少保留两种合理解释，不通过光线、颜色、道路、表情或构图标出正确答案。不要牌名、编号、标题栏、可读文字、logo、签名、水印、传统塔罗符号、魔法、光环、命运箭头、发光答案、善恶色码、日系动漫、Q版、摄影写实、3D、光滑矢量、厚重油画、暗黑哥特或数字喷枪质感。'
```

说明：

- 使用 `edit` 是为了传入风格参考图；提示词要求生成全新场景，不是在原图上改物件。
- `gpt-image-2` 不需要、也不接受 `--input-fidelity`。
- 最终图使用 `--quality high --size 1024x1536`。构图草稿可先改为 `--quality low`。
- 默认不覆盖同名输出；需要重新生成同名文件时再明确添加 `--force`。
- 真正调用需要配置 `OPENAI_API_KEY` 并允许网络访问。

## 0. 愚者｜未定之渡

现有图片已经准确承载“不确定条件下的开始”，建议直接作为 0 号基准卡。以下命令仅用于生成不覆盖原图的备选版本。

```bash
python3 "$IMAGE_GEN" edit \
  --model gpt-image-2 \
  --image "$CARD_STYLE_REF" \
  --prompt "$CARD_BASE_PROMPT

场景：清晨或午后的湖边普通木码头，一艘小型旧渡船靠岸。一名年轻人物背对观者，一只脚仍在岸边，另一只脚刚踏上连接岸与船的窄木跳板，一只手自然扶着船栏。人物的旅行包仍放在岸边，船门敞开，远岸被浅雾遮住但不显危险。
未完成关系：人物可能继续登船、先取回旅行包、等待更多信息或退回岸上；船不是逃离，岸也不是失败。
构图：人物、窄跳板、岸边旅行包和渡船形成清楚对角线，湖面、浅雾和天空占据较大留白。
避免：悬崖、坠落、胜利姿态、恐惧表情、发光航线、命运方向或传统愚者符号。" \
  --size 1024x1536 \
  --quality high \
  --out "$CARD_OUTPUT_DIR/00-未定之渡-v2.png"
```

## 生成后逐张检查

1. 缩到手机卡牌尺寸后，能否一眼看出主要人物、普通物件和未完成动作？
2. 不知道牌名的人，能否只根据画面说出“这里正在发生什么”？
3. 是否只有一个主要事件，而不是把 Markdown 中所有概念都塞进同一张图？
4. 是否至少存在两种现实解释，且没有明显的正确方向？
5. 是否避免用表情、明暗、颜色或空间位置推断动机、责任、人格和未来？
6. 场景是否符合该牌的“不得推断”，没有把抽卡变成建议或结论？
7. 女祭司与月亮、命运之轮与高塔、愚者与战车、死神与世界等相邻概念，能否仅凭场景明确区分？
8. 边框、纸张、线条、水彩、色板、人物简化程度和空气感是否与《未定之渡》一致？
9. 如果首轮已接近目标，下一轮只修正一个问题，并重复其余不可变项。
