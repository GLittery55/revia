日期：2026-08-30  
材料：陈曦、何维彤、江紫弦、束镇江、王萌五份访谈文本  
编码顺序：陈曦 → 何维彤 → 江紫弦 → 束镇江 → 王萌

## 1. 编码口径

- 本轮采用“意义单元切分—初始编码—持续比较—代码合并/拆分—阶段性范畴化”的滚动编码方式。
- 主要编码受访者回答；访谈者问题仅用于恢复上下文。知情同意、设备测试、网络中断和录制操作不编码。
- 《陈曦》开头的系统介绍和访谈提纲属于材料元数据，不作为受访者经验编码；其回答从原文 P009 开始。
- 自动转写中的明显口误或断句仅做语义层面的轻度归并，不替受访者补写观点。
- “较晚工作导致失眠”“运动、饥饿或疲劳导致脾气变化”等内容只编码为“受访者的因果归因/认可”，不当作已经得到验证的生理、心理或因果事实。
- 下文的“跨案例出现”表示某案例中存在明确材料，不表示统计频率、强度或总体可推广性。

## 5. 当前阶段的核心范畴与关系

### 核心范畴一：卡牌是一种“有条件的投射脚手架”

卡牌的价值并非来自图片本身，而来自它能否在合适时机提供开放但不过度强迫的联想空间。人物代入、情绪共鸣和自我生成会提高洞见的所有权、记忆度和参与动机；但当卡牌突然出现、关联度弱或必须按固定脚本解释时，同一机制会转化为认知负担和流程中断。

### 核心范畴二：有效反思表现为“温和支持下的具体化与可行动化”

受访者较认可的路径通常不是只安慰，也不是直接教育，而是：先准确理解现实难处和利害 → 把事件与整体人格否定分开 → 识别具体情绪、行为和可能情境 → 面对可改变的责任 → 形成低压力的小行动。

### 核心范畴三：用户能动性是一种可变的共同控制，而非主导权二选一

系统可以控制问题顺序、提醒注意方向、提供候选解释或生成建议，用户则提供经历、赋予意义、认可或拒绝推断。较好的体验接近“系统搭脚手架、用户最终解释”；重复协议、教师式语气或强迫关联会把这种脚手架推向牵引式控制。

### 核心范畴四：反思深度需要与当下目标和容量匹配

用户想倾诉、已经疲惫或事情本身较轻时，继续追问原因可能增加负担；用户想理清问题或采取行动时，更细的拆解更有价值。因此“基础支持型还是卡牌型更好”不是稳定结论，至少需要加入会话目标、精力和继续深挖的许可。

## 6. 初步过程模型（待后续材料检验）

`会话目标/反思准备度` → `准确理解与情绪承接` → `问题具体化` → `卡牌或问题脚手架` → `用户联想、确认或修正` → `事件—自我分离/行为责任` → `微行动`

可能的中断点：

1. 会话目标错配：只想倾诉，却被持续深挖。
2. 卡牌插入过早：叙述尚未完成，思路被截断。
3. 卡牌语义错配：用户只能“猜”联系。
4. 追问协议重复：开放探索变成机械任务。
5. 系统推断缺少确认：候选线索被呈现得像确定原因。
6. 语气权力感过强：挑战被体验为教师式说教。
7. 安全语境消歧失败：卡牌人物的假想叙事被误读为个人当前意图。

## 7. 方法与材料备忘

- 本轮是五个案例的第一轮滚动编码，适合形成敏感概念和后续采样问题，不足以宣称理论饱和或总体效果。
